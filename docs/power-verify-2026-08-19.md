## A. 公表値照合 — ✅ 合格

外部の錨として **R パッケージ MESS の `power_mcnemar_test(method="normal")`** を使った。
MESS は Connor (1987) の正規近似を実装しており、`power.py` の docstring が引いているのと同じ出典である。

照合を独立に保つため、MESS のソースを**その媒介変数(`paid` = 小さい方の不一致確率・
`psi` = 大きい方 / 小さい方)のまま逐語的に移植した**。contamlab の (d, ψ) 表現に直してから比べたら、
直す過程の代数が検証対象と癒着してしまう。

| 入力 | MESS の公表出力 | `required_n` | 差 |

| paid=0.100, psi=2, power=0.80, 両側 | **233.0945** | 234 | **0** |

★ 小数第4位まで一致した。**偶然ではありえない一致である。**

## B・C. 経験的な棄却率 — ❌ 不合格

`power.py` を一度も呼ばずに、**実際に検定を走らせて**棄却率を出した。

- **B(モンテカルロ)**: 標準ライブラリの `random` のみ。n=493・試行 **20,000**・seed **20260819**。
  p10 = 0.125 / p01 = 0.075(ψ=0.20・d=0.05)で不一致対を1問ずつ引き、`contamlab.stats.mcnemar.mcnemar_test` にかけた
- **C(厳密列挙)**: 乱数を使わず n_d ~ Binom(n, ψ)・b|n_d ~ Binom(n_d, π) を全項足し上げた(確率質量 1.000000 を回収)。
  **B の乱数誤差を切り離すための対照**

| 検定 | B 経験値(20,000 試行) | C 真値(決定的) | `power.py` の予言 |
|---|---|---|---|
| **contamlab の厳密条件付き検定**(実際に走るもの) | **0.7793** ±0.0057 | **0.7741** | 0.8000 |
| 正規近似検定(Connor の式が想定するもの) | 0.8081 | **0.8046** | 0.8000 |

★ **読み方はこうである**:

- 正規近似検定の真の検出力 **0.8046** は 0.80 にほぼ乗っている(ずれ +0.005 は正規近似そのものの誤差)。
  **⇒ 式は正しく、その式が対象とする検定の挙動も正しく予言している**
- ところが contamlab が判定に使っているのは**厳密条件付き検定**で、その真の検出力は **0.7741**。
  厳密検定は離散性ゆえ保守的(名目 α より実際の第1種過誤が小さい)なので、**検出力も下がる**
- **⇒ `power.py` は、このパイプラインが実際に走らせる検定より 3.0 ポイント楽観的な数字を返している**

### ついでに確かめられたこと(✅)

`mcnemar.py` の docstring は「`lcb > 0` ⟺ 片側の厳密 p 値 < α」が**厳密に成り立つ**と主張している。
20,000 試行で **食い違い 0 件**。★ **この主張は支持された。**

## 欠陥の記録(⛔ 直さない。編集禁止領域なので記録に留める)

### 欠陥 P-1 — `power.py` は `mcnemar.py` が使う検定の検出力を計算していない

- **所在**: [contamlab/stats/power.py](../contamlab/stats/power.py) 全体
- **中身**: `required_n` / `power_at_n` / `min_detectable_effect` は McNemar の**正規近似**検定の検出力を返す。
  一方 [contamlab/stats/mcnemar.py](../contamlab/stats/mcnemar.py) の `mcnemar_test` は**厳密条件付き**検定を実装しており、
  主要判定 `detected`(= `lcb > 0`)もそちらに紐づいている。**設計上のこの食い違いはどこにも書かれていない**
- **向き**: **常に楽観側。**厳密検定は保守的なので、`power.py` が「足りている」と言った標本でも実際には足りない
- **大きさ**: 看板の設定(ψ=0.20・d=0.05・α=0.05 片側)で検出力 0.80 → **実際 0.774**。必要 n は 493 → **527**
- **なぜ既存テストで捕まらなかったか**: `min_detectable_effect` と `required_n` の整合テストは
  **同じ式を両方向に使っているだけ**で、`mcnemar_test` を一度も呼んでいない。
  **`power.py` と `mcnemar.py` を突き合わせるテストが1本も無い**
- **⛔ 直さない理由**: `contamlab/stats/` は編集禁止領域。⛔ **また、事前登録([preregister.md](../preregister.md))が
  この検出力設計の上に立っているので、遡って書き換えたら事前登録の意味が消える。**
  ★ **既に実行済みのラン(`jmmlu-shuffle-03` の「検出下限 4.2pt / 5.1pt」など)の数字は、
  この分だけ楽観側に寄っている**と読むこと
